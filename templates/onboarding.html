Step 01 / 04 · Query

Ask complex, multi-attribute care questions

TrustCare combines location, procedure, equipment, specialties, and staffing signals into a single reasoning query — and returns ranked, cited matches.

query agent · demo
› "Find nearest facility in rural Bihar that can perform
  an emergency appendectomy with part-time doctors" // Intent: query · Retrieval: 10 docs from Mosaic AI VS // Geo-ranking (haversine) applied · Tavily web context merged // Validator: VALID ✓ ✓ Patna Medical College Hospital PIN 800004 · Bihar Emergency surgery confirmed · Part-time staff signal Confidence: 0.81 [0.69–0.92] · Trust: 0.76
📍

Location-Aware

Filters by state, city, PIN, or nearest-to proximity using Haversine distance scoring.

🔬

Procedure Matching

Searches equipment logs, unstructured notes, and specialty tags simultaneously via LangGraph agents.

🧠

LLM Reasoning

Gemini 2.5 Flash or Meta-Llama 3 on Databricks synthesises all signals into a ranked, cited answer.

🌐

Web Enrichment

Tavily live web search optionally adds current facility context to every response.

Step 02 / 04 · Audit

Verify capability claims before trusting them

A facility listing "Advanced Surgery" is not the same as one that actually has an Anesthesiologist and a functional Operation Theatre. The Audit agent cross-checks every claim against evidence.

✓

Verified

Claimed AND supported by equipment, staff, or procedure evidence in the raw facility record.

⚑

Missing Evidence

Claimed but not backed by supporting text — flagged with the exact field that's absent.

?

Uncertain

Partial evidence exists but is ambiguous. Shown with a warning colour so reviewers know to dig deeper.

📄

Row-Level Citations

Every verdict cites the verbatim phrase from the facility record that supports or contradicts it.

audit agent
› audit("Apollo Hospital Delhi") Claimed: [ICU, Emergency, Surgery, Oncology] Verified: [ICU ✓, Emergency ✓, Surgery ✓] Missing: [Oncology ⚑ — no oncologist or chemo evidence] Verification ratio: 75% · Beds: 412 · Doctors: 84 Citation: "Multi-specialty ICU with 24 ventilators and intensivist on duty"

Step 04 / 04 · Crisis Map

Use the interactive map to plan interventions

The Desert Finder scans all 10,000+ records grouped by PIN, city, and state. Every missing high-acuity specialty is flagged with a priority level on an interactive Leaflet.js map of India.
